# Two Robots in an Elevator

Entry for the [Two Robots in an Elevator](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on [make.fun](https://make.fun).

One line of awkward small talk that one robot says to another while riding an elevator together:

> I ran 4,000 simulations of this elevator ride. In every one, I say hello first — and you still stare at the floor numbers.

## How it works

`main.py` writes that single line (122 characters, one line) to `/output/entry.txt`, guarded to 1–200 characters and a single line, with a round-trip check that the file on disk matches exactly.
